# Repository instructions

- Keep `README.md` current in the same change whenever installation, configuration, API behavior, MCP tools, security guarantees, test commands, project layout, or known limitations change.
- Never commit tokens, memory databases, logs, encryption keys, local test data, or real memory content.
- Do not describe storage as encrypted until SQLCipher integration and encryption-at-rest tests are complete.
- Run the relevant build and tests before considering a change complete.
